# FAST Sports Analytics Website

Production-ready public website for FAST Sports Analytics.

## Repository placement

Upload **the contents of this folder** directly into the root of:

`FAST-Sports-Analytics/fast-platform`

Do not upload the outer ZIP or place these files inside another `FAST Website` folder.

The GitHub repository root should contain:

```text
app/
public/
package.json
next.config.ts
tsconfig.json
next-env.d.ts
.gitignore
README.md
```

## Deploying to Vercel

1. Import the `FAST-Sports-Analytics/fast-platform` repository.
2. Vercel should detect **Next.js** automatically.
3. Keep Root Directory set to `./`.
4. Keep the default build settings.
5. Select Deploy.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Contact link

The demo button currently opens an email to:

`contact@fastsportsanalytics.com`

Create that mailbox or forwarding address before publishing the site publicly.
